## 📱 Kontrol Jarak Jauh Lewat Smartphone (Web Remote)

Anda sedang di luar kantor atau tidak membawa laptop? Komputer Anda tetap dapat dikontrol langsung dari HP (Android / iPhone) atau browser apa pun tanpa perlu menginstal aplikasi tambahan:

👉 **[Buka Web Remote TamsDesk](http://tamsdesk.adityanatt.dpdns.org/web)**

### Fitur Mobile Controller:
- 👆 **Navigasi Sentuh:** Tap untuk klik kiri, tahan (*long-press*) untuk klik kanan.
- 📜 **Scroll Halus:** Geser 2 jari ke atas/bawah untuk melakukan scroll layar secara presisi.
- ⌨️ **Keyboard Virtual:** Ketik pesan, input teks, atau username langsung dari keyboard HP.
- 📋 **Sinkronisasi Clipboard:** Salin teks di HP lalu tempelkan (*paste*) langsung ke komputer target.

## 🚀 Panduan Cepat (3 Langkah Mudah)

### A. Jika Komputer Anda Ingin Diremote:
1. Buka **TamsDesk**.
2. Lihat kolom sebelah kiri pada kartu **ID TamsDesk Perangkat Ini**.
3. Bagikan **9-Digit ID** dan **PIN Keamanan** Anda kepada rekan atau teknisi yang ingin meremote.

### B. Jika Anda Ingin Meremote Komputer Lain:
1. Buka **TamsDesk** (atau buka [Web Remote](http://tamsdesk.adityanatt.dpdns.org/web)).
2. Masukkan **9-Digit ID Komputer Tujuan** pada kolom kanan.
3. Masukkan **PIN Keamanan Target** lalu klik **Hubungkan**.
